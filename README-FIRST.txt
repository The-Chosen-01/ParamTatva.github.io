PARAṀ TATVA WEBSITE | CONCEPT 02 MULTI-PAGE PROTOTYPE
======================================================

WHAT THIS IS
------------
A local, static HTML/CSS/JavaScript prototype built around the agreed earthy-modern editorial direction. It is not deployed and is not launch-ready. It intentionally makes missing or unapproved business details visible rather than inventing them.

HOW TO PREVIEW ON WINDOWS
-------------------------
1. Download and extract param-tatva-multipage-prototype.zip.
2. Open the extracted folder named param-tatva-multipage-prototype.
3. Double-click index.html. It should open in your browser.
4. Use the website navigation to open the separate pages.

If a browser blocks local file navigation on your system, keep the folder extracted and use a simple local web server, or ask for a guided way to preview it. Do not upload this prototype to the live domain yet.
